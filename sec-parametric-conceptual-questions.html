    Section 1 Conceptual Questions: Parametric Equations

    The following exercises review key conceptual ideas from Section 10.2 on parametric equations, including identifying the curve, determining direction of motion, recognizing repeated tracing, and comparing different parametrizations of the same geometric object.
    🔗

    Checkpoint 1.0.1.

    Which parametric equations trace the line segment from \((0,1)\) to \((2,5)\) along the line \(y=2x+1\text{?}\)
    🔗
    • \(x=t,\ y=2t+1,\ 0\le t\le 2\)
    • \(x=2t,\ y=4t+1,\ 0\le t\le 2\)
    • \(x=t,\ y=2t+1,\ -1\le t\le 1\)
    • \(x=t^2,\ y=2t^2+1,\ 0\le t\le 2\)
    Solution.
    The equations \(x=t\) and \(y=2t+1\) produce \(y=2x+1\text{.}\) When \(t=0\text{,}\) the point is \((0,1)\text{,}\) and when \(t=2\text{,}\) the point is \((2,5)\text{.}\) The other options either trace a larger portion, the wrong segment, or not the full segment in the intended way.

    Checkpoint 1.0.2.

    A particle moves according to \(x=\cos t\text{,}\) \(y=\sin t\text{,}\) for \(0\le t\le 4\pi\text{.}\) How many times is the unit circle traced?
    🔗
    • One-half time
    • One time
    • Two times
    • Four times
    Solution.
    The parametrization \(x=\cos t,\ y=\sin t\) completes one full revolution when \(t\) runs from \(0\) to \(2\pi\text{.}\) Since the interval is \(0\le t\le 4\pi\text{,}\) the circle is traced twice.

    Checkpoint 1.0.3.

    Consider the parametric equations \(x=t^2\text{,}\) \(y=t+1\text{,}\) for \(-2\le t\le 2\text{.}\) Which statement is true?
    🔗
    • The curve is a parabola traced exactly once from left to right.
    • The curve is part of a sideways parabola, and some \(x\)-values occur more than once.
    • The curve is a line segment traced from bottom to top.
    • The curve is the entire parabola \(y=x^2\text{.}\)
    Solution.
    Since \(t=y-1\text{,}\) substituting into \(x=t^2\) gives \(x=(y-1)^2\text{,}\) a sideways parabola. Because \(x=t^2\text{,}\) the same \(x\)-value occurs for both positive and negative values of \(t\text{.}\)

    🔗

    Checkpoint 1.0.4.

    Suppose \(x(t)\) is increasing and \(y(t)\) is decreasing on an interval. What can be concluded about the motion of the particle on that interval?
    🔗
    • The particle moves left and up.
    • The particle moves right and down.
    • The particle moves left and down.
    • The particle must move along a straight line.
    Solution.
    If \(x(t)\) is increasing, then the particle moves to the right. If \(y(t)\) is decreasing, then the particle moves downward. This does not imply the path is a straight line.

    Checkpoint 1.0.5.

    Which of the following parametrizations traces the line \(y=3x-2\) in the direction from left to right?
    🔗
    • \(x=t,\ y=3t-2\text{,}\) where \(t\) increases
    • \(x=-t,\ y=-3t-2\text{,}\) where \(t\) increases
    • \(x=t^2,\ y=3t^2-2\text{,}\) where \(t\) increases
    • \(x=\sin t,\ y=3\sin t-2\text{,}\) for all real \(t\)
    Solution.
    The first option gives \(y=3x-2\) and as \(t\) increases, \(x=t\) increases, so the motion is left to right. The second option traces the same line but with reversed direction. The other options do not trace the entire line in a simple one-pass left-to-right way.

    Checkpoint 1.0.6.

    Two parametrizations are given:
    🔗
    \(x=\cos t,\ y=\sin t,\ 0\le t\le 2\pi\)
    🔗
    and
    🔗
    \(x=\cos(2t),\ y=\sin(2t),\ 0\le t\le \pi\text{.}\)
    🔗
    Which statement is true?
    🔗
    • The second traces a larger circle.
    • The second traces the same circle twice.
    • The second traces the same circle once, but at a different speed.
    • The two curves are different because the parameter intervals are different.
    Solution.
    As \(t\) goes from \(0\) to \(\pi\text{,}\) the angle \(2t\) goes from \(0\) to \(2\pi\text{.}\) So the second parametrization traces the unit circle exactly once, but the parameter changes at a different rate.

    Checkpoint 1.0.7.

    A parametric curve is given by \(x=t^3\text{,}\) \(y=t^6\text{.}\) Which Cartesian equation describes the curve?
    🔗
    • \(y=x^2\text{,}\) for all real \(x\)
    • \(y=x^2\text{,}\) with \(y\ge 0\)
    • \(x=y^2\text{,}\) with \(x\ge 0\)
    • \(y=x^3\)
    Solution.
    Since \(x=t^3\text{,}\) we have \(x^2=t^6=y\text{.}\) Thus the curve satisfies \(y=x^2\text{.}\) Because squares are nonnegative, \(y\ge 0\text{,}\) which is consistent with the parabola.

    Checkpoint 1.0.8.

    Which statement best explains why two different parametric equations can describe the same geometric curve?
    🔗
    • Because parametric equations always produce infinitely many different curves.
    • Different functions of the parameter can produce the same set of points, possibly with different speeds or directions.
    • Because every Cartesian equation has only one possible parametrization.
    • Because changing the parameter always changes the geometric shape of the curve.
    Solution.
    A parametric curve is determined by the set of points traced and how they are traced. Different choices of parameter can produce the same set of points while changing orientation, speed, or how often the curve is retraced.

    Checkpoint 1.0.9.

    A particle moves according to \(x=\cos t\text{,}\) \(y=\sin t\text{,}\) for \(0\le t\le \pi\text{.}\) Which description is correct?
    🔗
    • The particle traces the entire unit circle clockwise.
    • The particle traces the upper semicircle counterclockwise from \((1,0)\) to \((-1,0)\text{.}\)
    • The particle traces the lower semicircle clockwise from \((1,0)\) to \((-1,0)\text{.}\)
    • The particle traces a line segment from \((1,0)\) to \((-1,0)\text{.}\)
    Solution.
    At \(t=0\text{,}\) the point is \((1,0)\text{.}\) At \(t=\pi/2\text{,}\) the point is \((0,1)\text{.}\) At \(t=\pi\text{,}\) the point is \((-1,0)\text{.}\) Thus the motion follows the upper semicircle counterclockwise.

    Checkpoint 1.0.10. Parametric Curve, Select all that apply.

    A particle moves according to \(x=t^2\) and \(y=t^2\) for \(-2\le t<2\text{.}\) Select all true statements about the curve and the motion of the particle.
    🔗
    • Every point traced by the particle lies on the line \(y=x\text{.}\)
    • Correct. Since \(x=t^2\) and \(y=t^2\text{,}\) we always have \(y=x\text{.}\)
    • The particle traces a line segment from \((0,0)\) to \((4,4)\text{.}\)
    • Correct. Because \(t^2\) ranges through all values from \(0\) to \(4\text{,}\) both \(x\) and \(y\) take the same values in that interval, so the traced set is exactly the line segment on \(y=x\) from \((0,0)\) to \((4,4)\text{.}\)
    • The parametric equations trace an arc of the parabola \(y=x^2\) from \((0,0)\) to \((4,4)\text{.}\)
    • This is false. Since \(x=t^2\) and \(y=t^2\text{,}\) eliminating the parameter gives \(y=x\text{,}\) not \(y=x^2\text{.}\) The curve is a line segment, not a parabolic arc.
    • The particle starts at \((4,4)\text{,}\) moves to \((0,0)\text{,}\) and then retraces the same segment back toward \((4,4)\text{.}\)
    • Correct. At \(t=-2\text{,}\) the particle is at \((4,4)\text{.}\) As \(t\) increases to \(0\text{,}\) \(t^2\) decreases to \(0\text{,}\) so the particle moves to \((0,0)\text{.}\) Then as \(t\) increases from \(0\) toward \(2\text{,}\) \(t^2\) increases again, so the particle retraces the same path.
    • All points on the curve are traced twice.
    • False. If \(0<a<4\text{,}\) then the point \((a,a)\) occurs for both \(t=\sqrt{a}\) and \(t=-\sqrt{a}\text{.}\) The origin is traced only once, at \(t=0\text{.}\) The point \((4,4)\) is approached again as \(t\to 2^-\text{,}\) but \(t=2\) is not included.
    • The particle is at the point \((4, 4)\) at some moment \(t\) .
    • This is true. The particle is at the point \((4,4)\) at time \(t=-2\text{.}\)
    Hint.
    Try eliminating the parameter first. Then think separately about the geometric curve and the direction of motion as \(t\) increases.
    🔗
    🔗
    Solution.
    Since \(x=t^2\) and \(y=t^2\text{,}\) we have \(y=x\text{.}\) Because \(-2\le t<2\text{,}\) the quantity \(t^2\) takes every value in the interval \([0,4]\text{.}\) Therefore, the geometric curve is the line segment from \((0,0)\) to \((4,4)\text{.}\) At \(t=-2\text{,}\) the particle starts at \((4,4)\text{,}\) moves toward \((0,0)\) as \(t\) increases to \(0\text{,}\) and then retraces the segment back toward \((4,4)\) as \(t\) increases from \(0\) toward \(2\text{.}\) Thus the true statements are that the curve lies on \(y=x\text{,}\) that it is the segment from \((0,0)\) to \((4,4)\text{,}\) that the particle retraces the segment, and that most points are traced twice.
