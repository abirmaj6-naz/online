    Section 1.2 10.3 Calculus and Parametric Equations

    Exercises Exercises

    We are still interested in lines tangent to points on a curve. They describe how the \(y\)-values are changing with respect to the \(x\)-values, they are useful in making approximations, and they indicate instantaneous direction of travel.
    🔗

    1. Exercise: Interpreting a horizontal tangent..

    Suppose a particle moves along a parametric curve and at \(t=t_0\) we have \(\dfrac{dy}{dt}=0\) and \(\dfrac{dx}{dt}\neq 0\text{.}\) What does this tell us?
    🔗
    • The tangent line to the curve is horizontal at the corresponding point.
    • Correct. When \(\dfrac{dy}{dt}=0\) and \(\dfrac{dx}{dt}\neq 0\text{,}\) the slope of the tangent line to the curve \(y(x)\) is \(\dfrac{dy}{dx}=0\text{.}\)
    • The particle has stopped moving completely.
    • \(\dfrac{dy}{dt}=0\) only means the vertical component of motion is zero at that instant.
    • The tangent line is vertical at the corresponding point.
    • A vertical tangent is associated with \(\dfrac{dx}{dt}=0\) and \(\dfrac{dy}{dt}\neq 0\text{.}\)
    • The curve must have a local maximum in \(y\text{.}\)
    • A horizontal tangent does not automatically imply a local maximum.
    🔗

    2. Exercise: Interpreting concavity for a parametric curve..

    At a point on a parametric curve, suppose \(\dfrac{d^2y}{dx^2}>0\text{.}\) Which statement best describes the graph near that point?
    🔗
    • The curve is concave up near that point (where the derivative is defined).
    • Correct. A positive second derivative indicates concave up behavior.
    • The curve must cross the \(x\)-axis at that point.
    • Concavity does not determine whether the curve crosses an axis.
    • The tangent line must be horizontal at that point.
    • Concavity and slope are different ideas.
    • The particle must be speeding up at that point.
    • Concavity of the graph is not the same as speed increasing.
    🔗

    3. Exercise: Horizontal and vertical tangents..

    Select all true statements about tangent lines to parametric curves.
    🔗
    • If \(\dfrac{dy}{dt}=0\) and \(\dfrac{dx}{dt}\neq 0\text{,}\) then the tangent line is horizontal.
    • Correct.
    • If \(\dfrac{dx}{dt}=0\) and \(\dfrac{dy}{dt}\neq 0\text{,}\) then the tangent line is vertical.
    • Correct.
    • If \(\dfrac{dy}{dt}=0\text{,}\) then the particle is not moving.
    • The particle may still be moving horizontally.
    • If \(\dfrac{dx}{dt}=0\text{,}\) then the tangent line must be horizontal.
    • This is the condition associated with a vertical tangent, provided \(\dfrac{dy}{dt}\neq 0\text{.}\)
    • A particle can be moving even when the tangent line is horizontal.
    • Correct. The horizontal component of velocity may be nonzero.
    🔗

    4. Exercise: Same curve, different parameterizations..

    Two particles move according to the parametric equations \(x=t,\ y=t^2\) and \(\overline{x}=2t,\ \overline{y}=4t^2\text{.}\) Select all true statements.
    🔗
    • Both particles trace the same parabola, but they may move along it at different rates.
    • Correct. Both parameterizations describe the curve \(y=x^2\text{,}\) but the parameter changes how the curve is traced.
    • The particles trace different curves because the equations are not identical.
    • Different parameterizations can describe the same geometric curve.
    • Since both parametrizations describe the same parabola, so \(\dfrac{dy}{dx}\) is equal to \(\dfrac{d\overline{y}}{d\overline{x}}\text{.}\)
    • Both particles move along the parabola \(y=x^2\text{,}\) but at different speed.
    • \(\dfrac{dy}{dx}\) is half of \(\dfrac{d\overline{y}}{d\overline{x}}\text{.}\)
    • Correct. The second particle moves at twice the speed of the first particle.
    • The second particle is faster than the first, so \(\dfrac{dy}{dx} \lt \dfrac{d\overline{y}}{d\overline{x}}\)
    • Correct. The second particle moves at twice the speed of the first particle.
    • Both particles have constant acceleration.
    • Correct. For the first particle the acceleration is 2 and for the second is 4 at any time \(t\)

      Match each condition for a parametric curve with the correct interpretation.
      🔗
    • \(\dfrac{dy}{dt}=0,\ \dfrac{dx}{dt}\neq 0\)

    • \(\dfrac{dx}{dt}=0,\ \dfrac{dy}{dt}\neq 0\)

    • \(\dfrac{dx}{dt}>0\text{,}\) \(\dfrac{dy}{dt}>0\)
    • The curve \(y=y(x)\) is increasing near \(x\text{.}\)
    • Constant speed
    • Clockwise motion
    • The curve \(y=y(x)\) is decreasing near \(x\text{.}\)

    6. Exercise: Select all that apply.

    Let a smooth curve be given by parametric equations \(x=f(t)\) and \(y=g(t)\) on \(a\le t\le b\text{.}\) Which of the following statements are true? Select all that apply.
    🔗
    • The arc length of the curve from \(t=a\) to \(t=b\) is \(\displaystyle L=\int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2+\left(\frac{dy}{dt}\right)^2}\,dt\text{.}\)
    • Correct. This is the standard arc length formula for a parametrically defined curve.
    • To determine concavity of a parametric curve, one typically studies \(\dfrac{d^2y}{dx^2}\text{,}\) not just \(\dfrac{d^2y}{dt^2}\text{.}\)
    • Correct. Concavity with respect to the graph in the \(xy\)-plane is determined by \(\dfrac{d^2y}{dx^2}\text{,}\) since this describes how the slope \(\dfrac{dy}{dx}\) changes as \(x\) changes.
    • If \(\dfrac{d^2y}{dt^2}>0\) on an interval, then the parametric curve must be concave up there.
    • Incorrect. Concavity of a parametric curve depends on \(\dfrac{d^2y}{dx^2}\text{,}\) not merely on \(\dfrac{d^2y}{dt^2}\text{.}\)
    • The arc length can always be found by integrating \(\displaystyle \int_a^b \left(\frac{dy}{dx}\right)\,dt\text{.}\)
    • Incorrect. Arc length depends on the total rate of change in both coordinates, so both \(\dfrac{dx}{dt}\) and \(\dfrac{dy}{dt}\) are needed.
    • If \(\dfrac{dy}{dx}\) is increasing as \(x\) increases, then the curve is concave down.
    • Incorrect. If \(\dfrac{dy}{dx}\) is increasing as \(x\) increases, then the curve is concave up.
    Hint.
    Separate the ideas: \(\dfrac{dy}{dx}\) gives slope, \(\dfrac{d^2y}{dx^2}\) gives concavity, and arc length measures the total distance traveled along the curve.

    7. Build the Arc Length Integral.

    Consider the parametric curve \(x(t)=t^3-3t,\quad y(t)=t^2+1,\quad -1\le t\le 2.\)
    🔗
    Arrange the blocks to form the correct expression for the arc length of the curve on the given interval.
    🔗
    Note: Some blocks are distractors and should not be used.
    🔗
    Answer.
    The correct arc length expression is
    \begin{equation*} \int_{-1}^{2}\sqrt{\left(3t^2-3\right)^2+\left(2t\right)^2}\,dt. \end{equation*}
    🔗
    🔗
    Solution.
    For a parametric curve \(x=x(t)\text{,}\) \(y=y(t)\text{,}\) the arc length on \(a\le t\le b\) is
    \begin{equation*} L=\int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2+\left(\frac{dy}{dt}\right)^2}\,dt. \end{equation*}
    🔗
    Here,
    \begin{equation*} \frac{dx}{dt}=3t^2-3,\qquad \frac{dy}{dt}=2t. \end{equation*}
    🔗
    Therefore,
    \begin{equation*} L=\int_{-1}^{2}\sqrt{\left(3t^2-3\right)^2+\left(2t\right)^2}\,dt. \end{equation*}
